# Sistema de Controle de Estoque

Projeto web desenvolvido para praticar e demonstrar conhecimentos em desenvolvimento front-end.

# Funcionalidades

* Cadastro e gerenciamento de produtos.
* Consulta e filtragem de itens.
* Controle de estoque e movimentações.
* Armazenamento de dados no navegador.
* Interface responsiva com tema escuro.

# Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

# Sobre o desenvolvimento

O projeto foi desenvolvido como parte do meu processo de aprendizagem em programação. Utilizei inteligência artificial como ferramenta de apoio para revisão e aprimoramento do código JavaScript e CSS, auxiliando na identificação de possíveis erros e melhorias.

O objetivo foi colocar em prática os conhecimentos adquiridos, compreender a estrutura da aplicação e evoluir minhas habilidades em desenvolvimento web.

# Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo index.html em um navegador.
